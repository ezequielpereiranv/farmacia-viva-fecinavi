VERSÃO FINAL PARA SERVIDOR LOCAL

1. NO COMPUTADOR QUE SERÁ O SERVIDOR
- Instale o Node.js LTS.
- Extraia este ZIP para uma pasta do computador.
- Dê dois cliques em INSTALAR.bat (somente na primeira vez).
- Depois dê dois cliques em INICIAR-SERVIDOR.bat.
- NÃO feche a janela preta enquanto a feira estiver acontecendo.

2. ACESSO
A janela do servidor mostrará os endereços da rede, por exemplo:
Pesquisa:  http://192.168.2.10:3000/pesquisa.html
Dashboard: http://192.168.2.10:3000/dashboard.html

Todos os tablets/celulares precisam estar na mesma rede Wi-Fi do computador servidor.

3. FLUXO DO PARTICIPANTE
- Responde às 7 perguntas SIM/NÃO.
- É levado automaticamente para a tela com 3 propostas.
- Pode apoiar (dar coração) em uma, duas, três ou nenhuma proposta.
- Finaliza e a tela fica pronta para o próximo participante.

4. DASHBOARD
- Aba Pesquisa: 7 gráficos em tempo real.
- Aba Propostas: ranking das três políticas por quantidade de apoios.
- Atualização automática via Socket.IO.

5. DADOS
Os resultados ficam armazenados localmente em:
data/resultados.json
Faça uma cópia desse arquivo antes de zerar, caso queira guardar os resultados.

6. ZERAR RESULTADOS
No dashboard clique em "Zerar resultados".

IMPORTANTE
O sistema funciona na rede local e não depende de banco de dados externo.
As fontes visuais usam Google Fonts; se não houver internet, o sistema continua funcionando usando Arial como alternativa.
