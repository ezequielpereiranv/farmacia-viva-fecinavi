FEIRA DE CIENCIAS - VERSAO WINDOWS
E.E. PRESIDENTE MEDICI - 8 ANO

OBJETIVO
Gerar dois arquivos para distribuicao:
1. Setup.exe - instala o aplicativo no Windows e cria atalho.
2. Portatil.exe - executa sem instalar.

IMPORTANTE
Somente o computador usado para GERAR os executaveis precisa ter Node.js e internet.
Os computadores onde Setup.exe ou Portatil.exe forem usados NAO precisam de Node.js, npm ou MongoDB.

COMO GERAR
1. Extraia esta pasta.
2. Execute GERAR-INSTALADOR-WINDOWS.bat.
3. Aguarde o download das dependencias e a compilacao.
4. Ao terminar, a pasta dist sera aberta automaticamente.
5. Guarde os arquivos .exe gerados.

AO ABRIR O APP
A Central do Servidor mostra automaticamente:
- IP do computador
- Porta utilizada
- endereco da Pesquisa
- QR Code da Pesquisa
- endereco e botao do Dashboard
- Relatorio / PDF
- total de participantes

REDE
O computador servidor e os tablets devem estar na mesma rede Wi-Fi/LAN.
Na primeira execucao, o Firewall do Windows pode pedir permissao para acesso a rede. Permita em rede privada.

DADOS
Os resultados sao salvos na pasta de dados do aplicativo do usuario do Windows, fora da pasta de instalacao, para nao serem perdidos em atualizacoes normais do programa.
